# Análise Exploratória de Dados: E-commerce Olist 

# Contexto e Objetivo
Este projeto foi desenvolvido para explorar a base de dados real da **Olist**, o maior marketplace do Brasil. O foco foi identificar padrões de consumo, entender a saúde logística da operação e fornecer insights que auxiliem na tomada de decisão estratégica.

# O que foi analisado:
* **Tendências de Vendas:** Identificação de sazonalidade e picos de demanda.
* **Eficiência Logística:** Comparação entre prazos prometidos e entregas reais.
* **Performance de Categorias:** Quais produtos geram maior volume de receita.
* **Geolocalização:** Distribuição geográfica de clientes e vendedores.

# Ferramentas e Tecnologias:
* **Python** (Linguagem principal)
* **Pandas & NumPy** (Manipulação e tratamento dos dados)
* **Matplotlib & Seaborn** (Visualização de dados e gráficos estatísticos)
* **Jupyter Notebook** (Ambiente de análise)
